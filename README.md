# Marcenaria Tubarão — Website Oficial de Vendas & Conversão

Página institucional e de vendas de alto padrão para a **Marcenaria Tubarão** (Móveis Planejados sob medida desde 1977 em Belo Horizonte - MG).

## Tecnologias Utilizadas
- **Framework:** Next.js 16 (App Router)
- **Estilização:** Tailwind CSS v4 com Design System customizado
- **Animações:** Framer Motion
- **Ícones:** Lucide React
- **Imagens e Favicons:** Sharp (Geração automatizada de favicons e ícones otimizados)
